# Kirshtein 2012 --- automorphisms of CD loops

## Why this source matters

Supplies the graded-automorphism count that Prop. 7.4's search is measured against.

## Claims taken from it

- **168 * 8 graded automorphisms of O**, extending diagonally.
- With the 16 sign changes e_g -> (-1)^mu(g) e_g, this gives the expected lower bound **2688 = 168 * 16** for graded automorphisms; the GL(4,2) search shows it is **attained for both S and S'**.

## Caveats

Loop automorphisms vs algebra automorphisms --- the graded count is the same for both algebras, so this invariant also fails to separate them. Only the full Aut does.
